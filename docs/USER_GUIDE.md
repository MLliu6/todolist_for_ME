# 用户使用指南

这份指南面向第一次打开 TodoList for ME 的用户。目标是用最短路径完成：创建任务、安排优先级、查看日历、管理重要日子、备份数据。

## 1. 第一次打开

推荐通过 GitHub Pages 或本地 HTTP 服务打开页面。

在线地址通常为：

    https://MLliu6.github.io/todolist_for_ME/

本地预览方式：

    cd /home/lml/vibecoding/todolist_for_ME
    python3 -m http.server 5173

然后在浏览器打开：

    http://localhost:5173/

不建议直接双击 `index.html`，因为 `file://` 环境下部分浏览器行为可能与真实网页环境不同。

## 2. 创建第一个任务

进入应用后，点击新建任务按钮，填写任务名称。

建议至少填写：

- 任务名称：一句话描述要做什么。
- 截止日期：任务的 DDL。
- 优先级象限：根据紧急程度和重要程度选择。
- 标签：例如论文、课程、实习、生活、项目。

保存后，任务会出现在日历和任务看板中。

## 3. 如何选择四象限

TodoList for ME 使用四象限法管理任务优先级。

- 紧急重要：必须尽快处理，例如今天截止的论文、马上开始的面试、已经逾期的重要任务。
- 紧急不重要：时间上很急，但价值不高，例如临时打扰、可以快速处理或委托的事务。
- 重要不紧急：对长期目标有价值，但不需要立刻完成，例如论文推进、项目开发、复习计划、能力建设。
- 不重要不紧急：价值较低，也不急，可以延后、删除或作为低优先级记录。

当前视觉语义中，任务看板和时间线使用：

- 红色：紧急重要。
- 绿色：紧急不重要。
- 黄色：重要不紧急。
- 白色或米白色：不重要不紧急。

日历中仍保留系统主题色，不强制使用四象限语义色，避免日历视图过于杂乱。

## 4. 日历视图怎么用

日历是主视图，用来观察任务和日期的关系。

常见用法：

- 月视图：查看整个月的任务分布。
- 周视图：查看本周任务压力。
- 日视图：查看某一天的具体任务。
- 点击日期：查看当天任务详情。
- 从日历中新建任务：适合直接围绕某个 DDL 创建任务。

如果某一天任务很多，建议进入任务看板或搜索视图进一步筛选。

## 5. 任务看板怎么用

任务看板用于按优先级组织任务。

常见操作：

- 查看每个象限下的任务列表。
- 拖拽任务改变顺序。
- 跨象限拖拽任务，调整优先级。
- 点击任务进入编辑。
- 勾选任务完成。
- 查看各象限已完成数量和总数。

建议每天先处理紧急重要任务，再推进重要不紧急任务。长期来看，重要不紧急任务是最能体现成长和积累的区域。

## 6. DDL 与逾期任务

设置 DDL 后，任务会和日历联动。

如果任务超过截止日期仍未完成，系统会标记为逾期。逾期任务不一定要立刻删除，可以根据实际情况选择：

- 继续推进。
- 修改 DDL。
- 拆成更小的子任务。
- 归档长期逾期任务，降低心理负担。
- 删除已经没有意义的任务。

## 7. 重复任务怎么用

重复任务适合周期性事项，例如：

- 每天背单词。
- 每周组会准备。
- 每月总结。
- 定期整理资料。

当重复任务被标记为完成后，系统会根据当前截止日期生成下一次任务。

## 8. 子任务 checklist 怎么用

复杂任务可以拆成子任务。

例如“完成论文实验”可以拆成：

- 整理数据。
- 跑 baseline。
- 跑改进方法。
- 统计结果。
- 画图。
- 写实验分析。

子任务适合帮助用户把大任务变成可执行步骤。

## 9. DaysMatter 重要日子

DaysMatter 用来记录值得关注的日期，例如：

- 考试日期。
- 面试日期。
- 论文截稿。
- 生日。
- 纪念日。
- 项目验收。
- 实习入职。

重要日子可以配置提前提醒任务。到触发日时，系统会自动生成对应任务，并避免重复生成。

## 10. 平行时间线

平行时间线按标签展示任务在时间上的分布。

它适合观察长期目标，例如：

- 论文任务在未来几周如何分布。
- 实习准备是否集中在某几天。
- 多个项目是否出现 DDL 冲突。
- 某个标签下是否长期没有推进。

如果同一轨道任务重叠，时间线会自动分层显示。

## 11. 任务能量场与能量推荐

任务能量场用气泡展示未完成任务的压力分布。气泡位置和大小会受到象限、精力消耗、子任务数量和逾期情况影响。

能量匹配推荐用于在不同精力状态下选择任务：

- 低精力：适合处理简单、短时、低压力任务。
- 中精力：适合推进普通任务。
- 高精力：适合处理重要任务、复杂任务和长期目标任务。

## 12. 数据备份与恢复

建议定期使用数据保险箱备份。

推荐流程：

1. 点击数据保险箱入口。
2. 输入至少 8 位口令。
3. 导出加密 HTML 或 JSON 文件。
4. 把文件保存在可信位置。
5. 换设备或换浏览器时，用同一口令导入。

注意：口令无法找回。忘记口令后，已加密文件无法恢复。

## 13. 推荐日常使用流程

每天打开后，可以按这个顺序使用：

1. 看日历，确认今天和近期 DDL。
2. 看任务看板，优先处理紧急重要任务。
3. 推进至少一个重要不紧急任务。
4. 根据当前精力查看能量推荐。
5. 完成任务后及时勾选。
6. 每周查看统计和时间线，调整后续安排。

## 14. 常见问题

### 为什么换浏览器后任务不见了？

因为数据默认保存在当前浏览器本地。换浏览器前需要使用数据保险箱导出备份，再到新浏览器导入。

### 为什么无痕窗口里的数据关闭后没了？

无痕窗口通常不会长期保存 localStorage 数据。正式使用请使用普通浏览器窗口。

### 为什么不建议直接双击 index.html？

直接双击会进入 `file://` 环境。部分浏览器能力、路径加载和安全策略可能与真实网页环境不同。推荐使用 GitHub Pages 或本地 HTTP 服务。

### 可以多人协作吗？

当前版本不支持多人协作。它是个人本地优先任务工具。

### 可以云同步吗？

当前版本不支持自动云同步。可以通过加密导出和导入在多设备之间迁移数据。
