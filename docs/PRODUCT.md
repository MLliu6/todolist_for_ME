# TodoList for ME 产品说明

TodoList for ME 是一个保护注意力的本地优先个人任务系统，面向每日行动、长期目标与重要日子管理。

它以“捕获 → 选择 → 执行 → 回顾 → 信任”为主循环，把 Today 首页、日历、四象限任务管理、DaysMatter、长期时间线、精力建议和加密数据保险箱整合到一个纯静态网页应用里。

## 产品定位

一个会替用户保护注意力、但绝不夺走控制权的本地优先日程清单。

适合：

- 学生管理课程、论文、实习、考试和长期目标。
- 科研/工程人员管理项目、实验、DDL、复盘节点。
- 想要将日历、任务优先级和重要日子统一管理的个人用户。
- 希望个人数据默认保留在本地、不依赖账号系统的用户。

## 当前核心能力

- Today 首页：快速捕获任务，并直接回答下一件事与今日负荷。
- 命令中心：使用 `Ctrl/Cmd + K` 搜索任务或跳转视图。
- 任务估时：为今日容量反馈提供轻量、可选的投入信息。
- 可恢复归档：被减速机制归档的任务可在首页恢复。
- 日历视图：按月、周、日查看任务和重要日期。
- 四象限任务看板：按紧急/重要程度组织任务。
- 计划日与 DDL：分开表达“哪天准备做”和“最晚哪天必须完成”，避免制造虚假逾期。
- 重复任务：支持周期性事项。
- 子任务 checklist：拆分复杂任务。
- 拖拽排序：调整任务优先级和象限。
- DaysMatter：记录生日、纪念日、考试、面试等重要日子。
- 任务遗传模板：从已有任务生成周期任务或关联任务。
- 平行时间线：按标签查看长期目标任务分布。
- 任务能量场：用位置和气泡大小理解任务压力。
- 能量匹配推荐：按当前精力推荐适合推进的任务。
- 加密数据保险箱：使用口令导出/导入本地数据。

## 视觉语义

当前版本采用 Atelier 视觉系统：暖中性底色承载内容，墨色建立结构，珊瑚橙只用于新增、完成和关键强调。

任务看板和时间线使用固定四象限语义色：

- 紧急重要：红色。
- 重要不紧急：深绿色。
- 紧急不重要：琥珀色。
- 不重要不紧急：中性灰。

日历保持系统主题色，避免在高密度日期网格中引入过多语义颜色。

## 隐私与数据

TodoList for ME 默认使用浏览器 localStorage 保存数据。任务、重要日子、标签等数据不会上传到服务器。

用户可以使用数据保险箱导出加密备份。导出文件由用户口令加密，口令不上传，也无法找回。清理浏览器数据可能导致本地数据丢失，建议定期导出备份。

## 当前产品边界

当前版本是纯静态网页应用，不包含账号系统、云同步和多人协作。它更适合作为个人本地优先工具，而不是团队协作 SaaS。

当前版本不提供：

- 自动云同步。
- 多人协作。
- 账号登录。
- 服务端备份。
- 口令找回。
- 移动端原生 App。
