# 隐私与数据说明

TodoList for ME 是一个本地优先的个人任务管理工具。默认情况下，任务、标签、重要日子、节气仪式、主题偏好等数据都保存在当前浏览器本地，不会主动上传到服务器。

## 1. 数据保存在哪里

当前版本主要使用浏览器的 localStorage 保存数据。常见数据项包括：

- `tdm_tasks`：任务、DDL、状态、象限、标签、子任务、重复规则等。
- `tdm_dm`：DaysMatter 重要日子。
- `tdm_tags`：用户自定义标签。
- `tdm_solar_rituals`：用户自定义节气仪式。
- `tdm_ui_prefs`：界面偏好，例如视图状态。
- 其他后续版本新增的本地配置项。

这些数据保存在用户当前使用的浏览器和当前站点域名下。换浏览器、换设备、清理浏览器数据或切换站点域名，都会影响数据是否可见。

## 2. 数据是否会上传

不会。当前版本是纯静态网页应用，不包含账号系统、后端数据库、云同步接口或远程数据收集服务。

仓库代码托管在 GitHub，页面可通过 GitHub Pages 访问，但用户在页面中创建的任务数据不会自动上传到 GitHub。

## 3. 数据保险箱如何工作

TodoList for ME 提供数据保险箱功能，用于导出和导入个人数据。

导出时，系统会把本地任务、标签、重要日子等数据打包，并使用用户输入的口令加密。导出的 HTML 或 JSON 文件只包含密文，不包含明文任务内容。

导入时，用户需要输入同一个口令解密文件。如果口令错误，数据无法恢复。

## 4. 口令能否找回

不能。口令不上传、不存储、不托管，也没有找回机制。

如果忘记口令，已经加密导出的文件无法解密。建议使用自己能够长期记住的口令，或保存在可信的密码管理器中。

## 5. 什么情况会导致数据丢失

以下操作可能导致本地数据丢失：

- 清理浏览器缓存或站点数据。
- 更换浏览器。
- 更换设备。
- 使用无痕模式后关闭窗口。
- 浏览器安全策略或扩展程序清理 localStorage。
- GitHub Pages 域名或访问路径发生变化。
- 手动删除 localStorage 中的相关 key。

建议定期使用数据保险箱导出加密备份。

## 6. 多设备使用建议

当前版本不提供自动云同步。如果需要跨设备使用，推荐流程是：

1. 在设备 A 中打开数据保险箱。
2. 输入口令并导出加密备份文件。
3. 将备份文件通过可信方式传输到设备 B。
4. 在设备 B 中打开 TodoList for ME。
5. 使用同一口令导入备份文件。

## 7. 公开分享注意事项

不要公开分享包含真实个人数据的加密备份文件。即使备份文件是密文，也应当把它视为私人文件。

如果需要展示产品功能，建议使用示例任务或测试数据。

## 8. 当前边界

当前版本不提供：

- 用户账号。
- 云端数据库。
- 多端实时同步。
- 团队协作。
- 服务端备份。
- 口令找回。
- 数据恢复客服支持。

TodoList for ME 更适合作为个人本地优先工具，而不是团队协作 SaaS。
