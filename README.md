# 📅 TodoList for ME

> 一个极简、高效、美观的个人任务管理工具，以日历为主视图，融合四象限法、自定义标签、DaysMatter 重要日子等功能。

## ✨ 功能特性

- 📆 **日历主视图** — 支持月度 / 周度 / 日度切换（已移除小时视图，避免伪精细化）
- 🎯 **四象限法** — 可视化象限选择器（右上=紧急重要，左上=不紧急但重要，右下=紧急不重要，左下=不紧急不重要）
- 🏷️ **自定义标签** — 支持自定义 + 已有标签快速选用
- ⏰ **DDL 管理** — 截止日期与日历联动高亮
- 🔁 **重复任务** — 支持每天 / 每周 / 每月重复，完成后自动生成下一次任务
- 🔎 **任务搜索** — 支持按任务名称、描述、标签、日期、状态和象限检索
- 📊 **任务统计** — 支持切换历史周/月，展示完成数、逾期数、四象限分布和标签分布
- 🧩 **子任务 checklist** — 任务详情内支持轻量子任务拆解与完成进度
- 🖱️ **拖拽排序** — 支持任务看板内排序与跨象限拖动
- 🧮 **四象限完成反馈** — 看板标题显示各象限 `已完成/总数`，快速判断推进情况
- ⏳ **时间胶囊任务** — 可设置解锁日期，未解锁前隐藏任务标题与内容，到期后自动显示
- 🌟 **DaysMatter** — 记录重要日子，显示距今天数
- 🎑 **节假日 & 节气** — 中国法定节假日、二十四节气（2026 年已按北京时间精确修正）、中西方重要节日
- 🌱 **节气任务建议** — 节气当天展示灵感任务卡，可一键添加；点击文案可原地编辑个人节气仪式
- 🔗 **DaysMatter 联动** — 重要日子可配置提前提醒任务，到触发日自动生成且防重复；卡片仅展示真实关联任务
- 🧬 **任务遗传模板** — 已有任务可转为模板，按日期周期或重要日子相对日期生成后续任务
- 🧘 **Burnout 减速提醒** — Q1 逾期压力过高时提供柔和提醒，可归档 7 天以上逾期任务且不删除数据
- 🧭 **平行时间线** — 按标签展示任务在时间上的分布，同轨道任务自动分层，hover 后展开详情
- 🫧 **任务能量场** — 独立气泡视图呈现所有未完成任务的紧急/重要和精力压力分布
- 🔋 **能量匹配推荐** — 按当前精力推荐适合推进的任务
- 🎨 **紫色系统主题 + 四象限语义色** — 系统主题保留低饱和紫色；任务看板和时间线使用红、绿、黄、白区分四象限语义，日历保持紫色体系
- ✨ **轻量玻璃质感** — 任务卡、统计卡和高级视图容器使用细边缘高光、柔和阴影和局部 hover 光泽
- 💾 **加密数据保险箱** — 数据默认存储在浏览器 `localStorage`，也可导出为带 AES-GCM 密文的 HTML/JSON，在其他浏览器输入口令恢复

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/MLliu6/todolist_for_ME.git
cd todolist_for_ME

# 推荐使用本地 HTTP 服务预览
python3 -m http.server 5173
```

浏览器打开：

    http://localhost:5173/

不建议直接双击 `index.html`，因为 `file://` 环境下部分浏览器行为可能与真实网页环境不同。

> **数据说明**：所有个人数据默认保存在当前浏览器 `localStorage` 中，不会上传至 GitHub。换浏览器或换设备时，点击右上角盾牌按钮打开“数据保险箱”，输入至少 8 位口令后导出加密 HTML；在另一个浏览器打开该 HTML 并输入同一口令即可恢复。导出的 HTML 只包含密文，不包含明文任务内容。

当前本地数据主要使用这些 `localStorage` key：`tdm_tasks`、`tdm_dm`、`tdm_tags`、`tdm_solar_rituals`、`tdm_ui_prefs`。旧数据缺少新字段时会按普通任务处理，不需要手动迁移。
